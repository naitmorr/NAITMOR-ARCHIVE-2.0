# Русский и английский контент

Русский — основной язык. Каждая запись имеет один locale и находится только
в `ru/` или `en/`. Не добавляйте titleRu/titleEn и другие двуязычные поля.
Не помещайте второй язык в основной текст той же записи.

1. Создайте запись в выбранной локали с соответствующим `locale`.
2. Для перевода создайте отдельный файл в папке другого языка.
3. Сохраните одинаковый `translationKey` внутри одной коллекции.
4. Переведите title, summary, основной текст, подписи и другие редакционные поля.
5. Перенаправьте смысловые ссылки на записи того же языка.
6. Выполните `npm run check`.

У переводов могут быть разные entryKey, но одинаковый translationKey.
Один translationKey не может встречаться дважды в одной коллекции и языке.
У музыкальных переводов должен совпадать kind; DEMO-флаг также должен совпадать.
Один и тот же исходный медиафайл может использоваться обеими локалями,
но alt и подпись записываются отдельно на нужном языке.

В коде: `getTranslation(collection, translationKey, locale)` возвращает только
опубликованный канонический перевод либо undefined. Автоматической подстановки
русского текста в английскую запись или наоборот нет.

`src/i18n/messages.ts` содержит отдельные типизированные словари UI.
Ключ, добавленный в русский словарь, должен быть добавлен в английский — это проверяет TypeScript.
Имена языков в переключателе являются отдельными настройками.

`getContentUrl()` использует существующий GitHub Pages base; русские адреса
не получают языкового префикса, английские — получают `/en/`. Эти функции
задают контракт будущих маршрутов; страницы переводов на этапе 2 не создаются.

Проверка письменности отклоняет кириллицу в английской прозе и латинские слова
в русской прозе, кроме явно разрешённых технических маркеров. Имена исполнителей,
авторов и псевдонимы — отдельные поля с сохранением оригинального написания.
Машинные ключи, ссылки и код не считаются локализованной прозой.

Это технический барьер от смешивания записей, не полноценное определение языка:
например, он не отличает английский текст от другого текста на латинице.
Качество перевода и корректность имён проверяются редактором.
