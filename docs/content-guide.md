# Работа с контентом

На этапе 1 подготовлены пустые каталоги. Добавление авторских материалов
начинается после утверждения и реализации схем на этапе 2.

| Материал | Каталог |
| --- | --- |
| Персонажи | `src/content/characters/` |
| Лор | `src/content/lore/` |
| События | `src/content/events/` |
| Альбомы, EP, синглы | `src/content/releases/` |
| Треки | `src/content/tracks/` |
| Метаданные артов | `src/content/artworks/` |
| Новости | `src/content/news/` |
| Сюжетные секретные материалы | `src/content/dossiers/` |

Будущий формат: Markdown с YAML-полями, проверяемыми Astro Content Collections.
Точные обязательные поля и шаблоны будут описаны здесь при внедрении коллекций.
Файлы `.gitkeep` сохраняют структуру в Git и не являются контентом.

Изображения размещаются отдельно в `src/assets/images/` по назначению.
Аудиопревью — в `public/audio/previews/`. Тяжёлые рабочие исходники и
аудиомастеры не предназначены для публикуемой сборки.

Материалы CLASSIFIED не имеют реальной защиты доступа. Публичный репозиторий
и опубликованные статические ресурсы доступны для чтения.
